# Freenish V1 prototype

A mobile-first static prototype for the Freenish curated free-furniture concept.

## What works
- Today's Finds feed
- One card per row
- Freenish Pick badge
- Colourful category navigation
- Search
- Category filtering
- Style/material/distance filters
- Newest/nearest sorting
- Original listing buttons
- Responsive mobile layout

## Run locally
Open `index.html` in a browser.

## Deploy to Render
Create a **Static Site** in Render and point it at this folder/repository. No server is required for this V1.

## Replace the demo listings
Edit `listings.js`. Each listing has:
title, category, style, material, distance, added, mins, pick, url.

The current URLs are placeholders and should be replaced with real original listing URLs before launch.
